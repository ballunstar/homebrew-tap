# Ballunstar Tap

## How do I install these formulae?

`brew install ballunstar/tap/<formula>`

Or `brew tap ballunstar/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "ballunstar/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
