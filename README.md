# ballunstar/homebrew-tap

```bash
brew install ballunstar/tap/vibewidget
vibewidget-refresh
```

[VibeWidget](https://github.com/ballunstar/vibe-widget) is a macOS menu bar app
and widget showing how much Claude and Codex usage is left.

It is built from source and signed with your own Apple Development certificate
— a free Apple ID issues one, no paid membership needed. Xcode is required to
build it, and `vibewidget-refresh` has to be run after every install and
upgrade; the formula's caveats say why.

`Formula/vibewidget.rb` is written here by the release workflow in the app's
own repository. Edit it there, not here.
